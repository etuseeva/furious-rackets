# Бешеные ракетки — сайт клуба

Одностраничный сайт клуба любителей бадминтона в Саратове.
Чистые HTML, CSS и JavaScript: ни сборки, ни зависимостей, ни бэкенда.

Содержимое сайта берётся из Google Таблицы, поэтому расписание, цены, акции и вопросы
можно менять без программиста. Если таблица не настроена или не отвечает — сайт
показывает стартовое содержимое из файла и никогда не остаётся пустым.

## Что где лежит

```
site/                      публикуемая папка — это и есть сайт
  index.html
  css/style.css
  js/config.js             ID Google Таблицы
  js/default-content.js    стартовое (запасное) содержимое
  js/app.js                загрузка данных и отрисовка блоков
  assets/                  логотип, маскот, иконки блоков, фавикон
  .nojekyll
content-template.xlsx      шаблон таблицы — загрузить в Google Таблицы
tools/build_template.py    скрипт, который собирает этот шаблон
.github/workflows/deploy.yml
```

## Как посмотреть локально

Самый простой способ — открыть `site/index.html` двойным кликом. Сайт работает
и так: стартовое содержимое лежит в обычном JS-файле, без запросов к серверу.

Если хочется проверить сайт ровно в тех условиях, что и на GitHub Pages
(и с подключённой Google Таблицей), запустите локальный сервер из папки `site`:

```bash
cd site && python3 -m http.server 8000
```

Дальше откройте http://localhost:8000 — остановить сервер можно по Ctrl+C.

## Как включить GitHub Pages

1. Залейте репозиторий на GitHub (команды — в конце файла).
2. Settings → Pages → Source: выберите **GitHub Actions**.
3. Дальше всё само: при каждом push в `main` workflow `.github/workflows/deploy.yml`
   публикует содержимое папки `site`. Его же можно запустить руками —
   вкладка Actions → Deploy to GitHub Pages → Run workflow.
4. Сайт появится по адресу `https://<логин>.github.io/<название-репозитория>/`.

## Как подключить Google Таблицу

1. Загрузите `content-template.xlsx` на Google Диск.
2. Откройте его и выберите Файл → Сохранить как Google Таблицы.
3. В таблице нажмите «Настройки доступа» → «Доступ по ссылке» → роль **Читатель**.
   Без этого сайт не сможет прочитать таблицу.
4. Скопируйте ID таблицы из адресной строки — это длинный кусок между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/`**`1AbCdEf...XyZ`**`/edit`
5. Впишите его в `site/js/config.js`:

```js
window.SITE_CONFIG = {
  SHEET_ID: "1AbCdEf...XyZ",
  TIMEOUT_MS: 6000
};
```

6. Закоммитьте изменение и запушьте — через минуту сайт начнёт брать содержимое из таблицы.

Дальше правите таблицу — сайт обновляется сам, заново публиковать ничего не нужно.
Изменения видны примерно через минуту: столько Google держит свой кеш.

### Что будет, если что-то пойдёт не так

Сайт задуман так, чтобы не ломаться ни при каких условиях:

- таблица не отвечает дольше 6 секунд, удалена, закрыта или вернула ошибку —
  показывается стартовое содержимое из `site/js/default-content.js`;
- лист переименован или в нём испорчены заголовки столбцов — этот блок берёт
  стартовое содержимое, остальные продолжают работать от таблицы;
- на листе не осталось видимых строк — блок и его пункт в меню просто исчезают,
  пустых заголовков на сайте не будет;
- пока данные грузятся, блоки скрыты, а первый экран виден сразу.

## Правила заполнения таблицы

Те же правила есть на первом листе шаблона — «Как заполнять».

**Не переименовывайте листы и не меняйте первую строку** (заголовки столбцов):
сайт ищет их по именам. Строки можно добавлять и удалять, столбцы — оставлять пустыми.
Полностью пустые строки сайт пропускает.

**Столбец «показывать»** есть почти на каждом листе.
Пусто или «да» — строка видна. «нет», «no», «0», «false» — строка скрыта.

**Столбец «до»** — дата в формате `31.12.2026` или `2026-12-31`. Строка пропадает
с сайта на следующий день после этой даты. Пусто — показывается бессрочно.
Так устроены акции и турниры: просроченный анонс исчезает сам.

**Расписание и площадки связаны** по короткому названию: в столбце «площадка» на листе
«Расписание» пишите название ровно так, как оно записано в столбце «название» на листе
«Площадки». Сайт подставит в расписание полное название и добавит в карточку площадки
дни тренировок.

- «уровни» — через запятую: `B, C+`. Пусто — на сайте будет «все уровни».
- «тип» — «рабочая» или «игровая» (игровые подсвечиваются салатовым).
- «цена» — только число, знак ₽ сайт добавит сам.
- «ссылка на карту» можно не заполнять: сайт построит ссылку на Яндекс Карты по адресу.

**Картинки** лежат в `site/assets`. В таблице указывайте путь вида `assets/tournament.jpg`
или полный адрес картинки в интернете. Новые картинки нужно добавить в репозиторий.

**Ссылки внутри текста.** В любом тексте — ответах FAQ, описаниях тренировок, акциях, турнирах —
можно поставить `{телефон}`, `{тренер}` или `{группа}`. Сайт заменит их на кликабельные ссылки,
взяв номер и адреса из «Настроек». Сам адрес писать не нужно, и при смене номера или тренера
править тексты не придётся.

**Ссылки в столбцах** принимаются только вида `https://`, `http://`, `tel:`, `mailto:` и пути внутри
сайта. Всё остальное сайт игнорирует — это защита от чужих скриптов в таблице.

**Лист «Настройки»**: столбец «ключ» не трогайте, меняйте только «значение».
Телефон и Telegram тренера в репозитории намеренно заглушечные — настоящие вписывайте сюда.
`phone` — номер на главной кнопке, `phone_name` — подпись под ним (кто возьмёт трубку).
`group_telegram` — группа, куда ведёт кнопка «Группа в Telegram».

**Лист «Соцсети»** — список ссылок внизу страницы: ВКонтакте, Instagram, MAX.
Строки можно добавлять и убирать, порядок на сайте такой же, как в таблице.

## Как пересобрать шаблон таблицы

Нужно, только если меняли стартовое содержимое в `site/js/default-content.js`
и хотите, чтобы шаблон совпадал с ним. Скрипт читает тот же файл, поэтому данные
не расходятся.

```bash
python3 -m pip install openpyxl && python3 tools/build_template.py
```

## Как залить на GitHub

Репозиторий уже создан локально, первый коммит сделан. Осталось привязать удалённый:

```bash
git remote add origin https://github.com/<логин>/<репозиторий>.git
```

```bash
git push -u origin main
```
